# Extension B2B — V1

Objectif : permettre à un professionnel de gérer plusieurs mariages sans mélange, sans rien changer pour les particuliers.

Aujourd'hui chaque module range ses données sous l'identifiant du compte (budget, checklist, prestataires, invités, plan de table, documents, jour-J…). Un compte = un mariage. On introduit donc une entité « mariage » à laquelle les modules du périmètre se rattachent.

Parcours :
- Particulier : connexion → tableau de bord actuel, à l'identique.
- Professionnel : connexion → « Mes mariages » → ouverture d'un mariage → le même tableau de bord, dans le contexte choisi, avec retour permanent vers la liste.

Aucune refonte visuelle : composants, mises en page et styles existants réutilisés tels quels. Aucune nouvelle route de module.
