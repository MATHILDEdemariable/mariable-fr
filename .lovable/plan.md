# Ajustement de l’offre Mariable Pro

## Objectif
Clarifier la valeur de Mariable Pro sur la page `/partenariat`, en présentant d’abord l’application professionnelle puis la visibilité auprès des couples.

## Modifications prévues
- Réécrire l’offre principale pour mettre en avant en premier l’application Mariable.fr, notamment le module Jour-J, puis le référencement et la visibilité B2C.
- Dans le détail de l’offre, afficher clairement les deux volets sous la forme : **Application Mariable.fr + Référencement & visibilité**.
- Remplacer la formulation générique sur les fonctionnalités par : **nombre de projets illimité avec utilisation des fonctionnalités IA**.
- Retirer le bouton « Voir les conditions d’admission » de l’encadré tarifaire « Offre de rentrée » afin de conserver un seul bouton principal : « Rejoindre Mariable Pro ».
- Conserver le lien discret vers les conditions d’éligibilité dans le bloc Référencement, afin que l’information reste accessible.
- Reporter les mêmes ajustements dans la version anglaise pour préserver le fonctionnement du sélecteur FR/EN.

## Vérification
- Contrôler les textes, l’ordre de présentation et l’unicité du bouton sur mobile et ordinateur.
- Vérifier que « Rejoindre Mariable Pro » ouvre toujours le formulaire professionnel attendu.
- Vérifier que les conditions d’éligibilité restent accessibles depuis le bloc Référencement.
